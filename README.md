# Face Shape Finder

make a face shape app. basically an app which sees ur face, analyses it, tells ur probability of the face shape, and recommends hairstyles for it. Take a data of all kinds of face shapes, and keep atleast 5 hairstyle per shape, 5 for men, 5 for women.
